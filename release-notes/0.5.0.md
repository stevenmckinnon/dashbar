- **Plan limit alerts**: a notification when a Claude or Codex limit reaches 80%, when it's on course to run out before it resets, and when it's used up. Once per window
- **Needs you**: when Claude stops to ask for permission or an answer, Dashbar shows it in amber, puts it first, counts it beside the menu bar icon and can notify you. A permission prompt no longer sends a false "finished" notification
- **⌃⌥D** opens the Dashbar window from anywhere, and closes it again
- Each new notification can be turned off in Settings
- Claude plan limits cope with Claude's rate limiting: Dashbar waits before asking again and keeps showing the last reading, instead of an error
