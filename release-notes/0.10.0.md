- GitHub Copilot support, in the terminal and as VS Code's agent: its sessions show in your workspaces as working, idle or asking permission, with notifications, the island and the menu bar like any agent. A Usage card and History show its tokens, models and premium requests, updated when a session ends, which is when Copilot saves them. Add Dashbar's hook in Settings → Integrations to see when a session needs you the moment it asks.
- A Show in Dashbar switch for each tool in Settings → Integrations: Codex, Gemini CLI and Antigravity, OpenCode and GitHub Copilot. Switched off, a tool is hidden everywhere and Dashbar stops reading its files; switch it back on and everything returns.
