- **The dashbar command**: type `dashbar` in Terminal to see which agents need you, which are working and how much of each plan limit is left, or put `dashbar line` in your tmux status bar or shell prompt. It reads what Dashbar already shows, so Dashbar has to be running. Homebrew adds it to your PATH; with the DMG, copy the command from Settings → Integrations
- **A notification when a used-up limit resets**: once a 5-hour or Weekly limit has been used up, Dashbar tells you when it resets so you can pick up where you left off. It's covered by the same setting, now "When a plan limit runs low or resets"
- The Claude Code status line script no longer writes session ids to disk. Dashbar updates the script by itself the next time it opens
- `brew uninstall --cask --zap dashbar` now also removes Dashbar's caches
