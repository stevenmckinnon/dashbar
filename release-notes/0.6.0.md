- **The Dashbar window**: the pop-out button or ⌃⌥D now opens Dashbar as a full window, with Overview, Agents, Servers, System, Clean-up and every running workspace in a sidebar. The menu bar panel stays the quick glance
- **A page for each workspace**: its uptime, CPU, memory and energy, adding up its dev servers, its agents and everything they started, with its dev servers, agents and the processes behind the numbers. Open it from the sidebar, a workspace card, or the name or chart button in the panel
- A filter at the top of the sidebar (⌘K) narrows the workspaces and the page you're on
- On macOS 26 and later, the filter fields and the window's buttons use Liquid Glass
- The window shows the checked-out git branch for each workspace
