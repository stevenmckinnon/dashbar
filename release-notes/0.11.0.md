- A new keyboard shortcut jumps to the agent that needs you: it brings forward the app of the session that has waited longest for you, or, if none is waiting, the one that finished last. Set it in Settings → General (there's none until you pick one). Tools switched off in Show in Dashbar are skipped.
- Settings → About has Copy Diagnostics: a short summary for a bug report (Dashbar's and macOS's versions, which tools and integrations Dashbar found, any format warnings, the widgets' state, how many extra accounts and where Claude's plan limits come from). It never includes project names, folders, sessions or account names, Show Diagnostics lets you read it before you copy, and nothing is sent.
